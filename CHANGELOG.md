# Changelog

## 0.6 — Beta
- Added **Go to Nuvio**, **Exit to home** and **Stop ARNu** actions.
- Closing the settings activity does not disable automatic rewind.
- Reduced unnecessary periodic session checks while rewind is disabled.

## 0.5 — Beta
- Redesigned the Android TV interface with remote-friendly controls and status.
- Kept adjustable rewind and minimum-pause settings.

## 0.4 — Beta
- Added configurable minimum pause duration (0–120 seconds).

## 0.3 — Beta
- Added boot-time reconnection, auto-start switch and ARNu app icon.
- Added adjustable rewind duration.

## 0.2 — Prototype
- Added background notification-listener monitoring for Nuvio sessions.
- Verified automatic seek on playback resume.

## 0.1 — Prototype
- Initial media-session diagnostic build.
